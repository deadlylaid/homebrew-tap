# deadlylaid/homebrew-tap

Homebrew casks for [DigiTokenBar](https://github.com/deadlylaid/DigiTokenBar).

```sh
brew install --cask deadlylaid/tap/digitokenbar
brew upgrade --cask deadlylaid/tap/digitokenbar
```

DigiTokenBar is signed with a self-signed identity and not notarized, so the cask clears the download
quarantine after install. Release builds update `Casks/digitokenbar.rb` automatically.
